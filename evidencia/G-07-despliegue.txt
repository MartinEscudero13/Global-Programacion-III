================================================================================
1. Servicios
================================================================================
El panel no permite crear un proyecto nuevo (responde «You are not allowed to
create more projects» y canCreateProject devuelve false con los tres proyectos
existentes), así que los servicios del Global viven dentro del proyecto del
grupo, con el prefijo libreria- para no mezclarse con los de otras materias.

  zoriontech-crm_libreria-db        postgres:18-alpine        1/1
  zoriontech-crm_libreria-backend   app, Build Path /backend  1/1
  zoriontech-crm_libreria-frontend  app, Build Path /frontend 1/1

Nombre interno del backend: zoriontech-crm_libreria-backend:8000.
El backend no tiene dominio público: sólo se alcanza por la red interna.

================================================================================
5. Construcción de la imagen del frontend
================================================================================
Local, con Docker Desktop:

  cd frontend
  docker build -t libreria-frontend .
  docker run -d --name libreria-frontend -p 127.0.0.1:8080:80 \
    -e API_UPSTREAM=host.docker.internal:8000 libreria-frontend

  BUILD_EXIT=0 · libreria-frontend:latest 92.9 MB · nginx/1.30.6
  /api/health/ready → 200 · / → 200 · /no-existe.html → 404
  docker logs sin errores ni warnings

En Docker Desktop no se pasa --add-host: con ese flag, host.docker.internal
resuelve primero a IPv6 y Nginx registra un error transitorio de conexión.

En Easypanel el mismo Dockerfile se construye con Build Path /frontend y el
argumento de entorno API_UPSTREAM=zoriontech-crm_libreria-backend:8000.
